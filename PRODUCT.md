# Product

## Register

product

## Users

DSH users who configure persistent memory while working in the Web settings panel. They need to understand which memory behaviors are active and adjust limits without reading configuration files.

## Product Purpose

Hermes provides scoped, durable memory for DSH sessions. Its settings page exposes enablement, automatic capture, session-start recall, retention, and background review controls with the same interaction language as the native DSH settings pages.

## Brand Personality

Clear, restrained, trustworthy. The page should feel like a native DSH settings section rather than a separate plugin dashboard.

## Anti-references

Avoid washed-out labels, dense ungrouped controls, decorative card stacks, custom color tokens that ignore DSH themes, and settings that require users to infer the effect of a switch from its position alone.

## Design Principles

- Use the DSH theme and control vocabulary so the plugin remains visually native in both color schemes.
- Group controls by the user decision they support, not by implementation order.
- Put a concise explanation beside settings whose effect is not obvious.
- Keep advanced limits visible but subordinate to their controlling feature.
- Preserve keyboard access, readable contrast, and predictable native form behavior.

## Accessibility & Inclusion

Use theme-provided text colors with at least WCAG AA contrast for normal text, preserve visible native focus states, keep every control keyboard reachable, and do not rely on color alone to explain enabled or disabled state. The page has no required motion.
