# Hermes Memory 数字输入框设计

## 目标

让记忆设置页的数字输入框接近 DSH 原生 Input，同时保留数字输入语义、键盘操作、最小值/最大值约束和现有设置保存行为。

## 视觉方案

- 输入框高度固定为 32px，圆角为 8px，宽度沿用当前桌面端 96px 和窄屏 84px。
- 使用 DSH 的边框、背景、主文字和品牌色 token，避免浏览器默认白底和默认边框脱离页面主题。
- 聚焦时使用品牌色边框和可见焦点轮廓，保持键盘操作可识别。
- 隐藏浏览器默认数字微调箭头，避免控件显得像未定制的原生表单。
- 禁用状态保留可读性，通过降低透明度表达不可编辑状态。

## 验收标准

- `MemorySettings` 继续渲染 `input type="number"`，不改变数值变更回调。
- 样式包含 DSH Input 的尺寸、圆角、主题 token、焦点态和数字微调箭头处理。
- 客户端测试、类型检查和生产构建通过。
