# Hermes Memory Switch 控件设计

## 目标

将设置页中的布尔选项改为紧凑的滑动 Switch，使开启和关闭状态更容易识别，并保持 DSH 原生设置页的视觉语言。

## 方案

保留 `<input type="checkbox">` 作为实际交互控件，用 CSS 将其默认外观隐藏，并在相邻元素上绘制轨道和圆形滑块。外层继续使用 `<label>`，因此点击文字、鼠标操作和键盘操作都沿用原有语义。

开启状态使用 DSH 的 `--dsw-alias-state-success-primary`，关闭状态使用 DSH 的中性边框和交互背景 token。焦点状态使用可见 outline，保存请求期间通过现有 `disabled={saving}` 保持不可操作。

## 验收

- 每个设置开关仍暴露为带有原有标签的 checkbox。
- 开启状态显示绿色轨道和右侧滑块，关闭状态显示中性轨道和左侧滑块。
- 浅色和深色主题不使用硬编码颜色，键盘聚焦可见。
- 减少动态效果设置开启时不依赖过渡动画。
- 构建产物包含 Switch 样式，且不包含旧的 `--dsh-fg-*` 变量。
