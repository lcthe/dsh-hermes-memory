# dsh-hermes-memory 设置页视觉与交互设计

## 目标

把 Hermes Memory 设置页调整为 DSH 原生设置页的产品风格。改动只涉及客户端呈现，不改变设置字段、默认值、持久化协议和 Host 行为。

## 页面结构

设置页保留现有的说明文字，并按用户决策拆成四组：

1. 基础记忆：启用记忆工具、项目记忆、默认检索条数。
2. 自动捕获：总开关、偏好/约定/纠正捕获、失败工具上下文、每会话上限。
3. 新会话注入：自动注入、用户/项目记忆范围、注入条数和字符上限。
4. 保留策略与后台复盘：过期清理、保留天数、失败记忆保留天数、后台复盘和复盘预算。

每组使用原生设置页的标题和分隔关系，不使用独立卡片、渐变、装饰插图或自定义面板背景。由上层设置 shell 负责页面标题和导航，Hermes 组件只负责内容和字段交互。

## 视觉规则

- 主文本使用 `--dsw-alias-label-primary`，说明文字使用 `--dsw-alias-label-secondary` 或 `--dsw-alias-label-tertiary`。
- 页面使用原生设置区的字号、行高、控件高度、边框和圆角，不再使用不存在的 `--dsh-fg-*` 变量。
- 每一行采用左侧标签/说明、右侧控件的布局，标签列允许收缩，数字输入保持稳定宽度。
- 组标题使用原生主文本层级，辅助说明使用较低层级但保持可读对比度。
- 依赖开关未开启时，子项保持隐藏或禁用，避免显示不能产生效果的设置。
- 布局在窄窗口下允许标签和控件自然换行，不能产生水平溢出。

## 交互与行为

- 所有字段继续通过现有 `settingsScope` 更新，更新中的控件保持不可操作。
- 复选框和数字输入沿用原生 HTML 控件语义，不添加鼠标专属行为。
- 自动捕获、自动注入和后台复盘的默认关闭状态保持不变。
- 开关旁的说明文字明确说明触发时机、作用范围和安全限制。

## 验收标准

- 浅色和深色主题下，所有标签、说明、组标题和控件均清晰可读。
- 页面视觉层级、行间距和控件风格与 DSH 原生设置页面一致，不再出现当前截图中的低对比度文字。
- 所有设置字段仍可正常读写，现有设置测试和新增样式回归测试通过。
- 构建产物中的客户端 CSS 使用 DSH 主题变量，且不包含旧的 `--dsh-fg-*` 变量。
- 页面在窄窗口中不产生横向溢出。
